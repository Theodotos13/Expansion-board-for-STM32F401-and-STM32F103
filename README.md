# Expansion-board-for-STM32F401-and-STM32F103
This is the source code and firmware demonstrating the capabilities of a power expansion board designed for STM32F401 (Black Pill) and STM32F103 (Blue Pill) development boards. You can view the schematic and PCB design here: https://oshwlab.com/b_bikman/project_lsxkgfyc

Это исходный код и прошивка для демонстрации возможностей силовой платы расширения для отладочных плат STM32F401 (black pill) и STM32F103 (blue pill). Схему и плату моно посмотреть здесь: https://oshwlab.com/b_bikman/project_lsxkgfyc
